# 渠订通部署说明

当前版本：1.3.4

## Docker Compose

```bash
mkdir -p /opt/qudingtong/data/security /opt/qudingtong/backups
cd /opt/qudingtong
curl -O https://raw.githubusercontent.com/xiaolurenya/qudingtong/main/docker-compose.yml
curl -O https://raw.githubusercontent.com/xiaolurenya/qudingtong/main/.env.example
cp .env.example .env
# 修改 .env 中的 BOOTSTRAP_ADMIN_PASSWORD
docker compose up -d
```

访问 `http://服务器IP:8282`。

## 环境变量

- `SESSION_SECRET`：会话密钥；留空首次启动自动生成
- `QDT_BACKUP_PEPPER`：加密备份密钥；留空首次启动自动生成
- `QDT_AGENT_TOKEN`：打印代理 Token；留空可在后台安全中心轮换
- `QDT_SECURE_COOKIE`：HTTP 直连 `0`；启用 HTTPS 后设为 `1`
- `QDT_UID` / `QDT_GID`：挂载目录所属 UID/GID

正式建议使用 `openssl rand -hex 32` 生成会话密钥和备份密钥。

## 初始账号

首次启动会按 `.env` 创建管理员，并生成内置员工/演示账号。请在首次登录后立即修改所有初始凭据；本文不在公开文档中提供固定口令。

## 数据目录

- 主库：`./data/qudingtong.db`
- 安全库：`./data/security/qudingtong-security.db`
- 备份：`./backups`

不要执行 `docker compose down -v`。

## 授权

进入后台「安全中心 / 授权信息」查看机器码，联系作者获取统一永久授权码。备份恢复不会携带授权码、设备指纹或会话；换机后需重新激活。

## 打印代理

```bash
QDT_URL=http://服务器IP:8282 \
QDT_AGENT_TOKEN="后台生成的代理 Token" \
node print-agent.mjs
```

代理每 3 秒拉取待打印任务，调用本机 `lp/lpr` 后回写状态。Windows 打印代理模板位于私有源码仓。

## 升级

```bash
docker compose pull
docker compose up -d
```

升级前请在后台导出加密备份，并保留 `data` 与 `backups` 目录。
