# 宝塔 / systemd 部署

当前版本：1.3.4

## 目录

- 网站根目录：`/www/wwwroot/qudingtong`
- 主数据库：`/www/wwwroot/qudingtong/data/qudingtong.db`
- 安全数据库：`/www/wwwroot/qudingtong/data/security/qudingtong-security.db`
- 备份目录：`/www/wwwroot/qudingtong/backups`

## 安装

```bash
cd /www/wwwroot/qudingtong
bash deploy/baota/install.sh
```

安装脚本会创建数据目录、独立安全库、随机密钥和 `.env`，并配置 systemd 以 `www` 非 root 用户运行。

## 安全建议

- 配置 HTTPS 后设置 `QDT_SECURE_COOKIE=1` 并重启服务
- 首次启动后立即修改默认管理员、员工和演示客户密码
- 主库、安全库、`.env` 与备份目录权限保持 600/700
- 定期导出加密备份并异地保存
- 不要在公网暴露数据库目录

## 多进程

默认 `WEB_CONCURRENCY=4`。可通过 systemd 环境变量调整。系统内置 SSE 广播与 revision 轮询，多 worker 下订单、库存、账单和退货状态可实时同步。

## 打印

打印代理使用 `QDT_AGENT_TOKEN` 或管理员 Cookie + CSRF 模式。建议生产环境使用独立 Token。
